# My Portfolio App - Android 🚀

¡Bienvenido a mi portafolio profesional en Android! Esta aplicación ha sido desarrollada nativamente para mostrar mi trayectoria, habilidades técnicas y proyectos destacados como desarrollador Android.

Desarrollado con ❤️ por **Adrian Alvarez**.

## 🎯 Propósito del Proyecto

El objetivo de esta aplicación es proporcionar una plataforma interactiva y moderna para presentar mi perfil profesional como desarrollador Android. A diferencia de un CV estático, esta app permite experimentar de primera mano la calidad de mi código, mi dominio de Jetpack Compose y mi capacidad para implementar arquitecturas robustas y escalables.


## ✨ Características

- **Diseño Moderno:** Interfaz de usuario elegante y minimalista utilizando **Material 3**.
- **Arquitectura Robusta:** Implementación de **Clean Architecture** para una separación de conceptos clara y mantenible.
- **Navegación Fluida:** Sistema de navegación intuitivo entre las diferentes secciones del portafolio.
- **Secciones Detalladas:**
  - 🏠 **Home:** Introducción y perfil profesional.
  - 💼 **Experiencia:** Trayectoria laboral y logros principales.
  - 🚀 **Proyectos:** Galería de proyectos destacados con descripciones.
  - 🛠️ **Tech Stack:** Tecnologías y herramientas que domino.
  - 📧 **Contacto:** Formulario integrado para comunicación directa.
- **Animaciones Premium:** Experiencia de usuario mejorada con transiciones suaves y pantallas de carga dinámicas.

## 🛠️ Stack Tecnológico

- **Lenguaje:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Arquitectura:** MVVM (Model-View-ViewModel) + Clean Architecture
- **Inyección de Dependencias:** [Koin](https://insert-koin.io/)
- **Networking:** [Retrofit](https://square.github.io/retrofit/) & [Kotlinx Serialization](https://github.com/Kotlin/kotlinx.serialization)
- **Carga de Imágenes:** [Coil](https://coil-kt.github.io/coil/)
- **Componentes de UI:** Material Design 3

## 🏗️ Estructura del Proyecto

El proyecto sigue los principios de Clean Architecture:

- **`data`:** Implementaciones de repositorios, fuentes de datos remotas (API) y locales.
- **`domain`:** Lógica de negocio pura, modelos de dominio y definiciones de repositorios.
- **`presentation`:** Componentes de la interfaz de usuario (Screens, Components), ViewModels y State management.
- **`di`:** Configuración de los módulos de inyección de dependencias con Koin.
- **`ui`:** Definición del sistema de diseño (Temas, Colores, Tipografía).

## 🚀 Instalación y Uso

1. Clona este repositorio:
   ```bash
   git clone https://github.com/Cordobot/MyPortfolioApp.git
   ```
2. Abre el proyecto en **Android Studio (Iguana o superior)**.
3. Sincroniza el proyecto con los archivos Gradle.
4. Ejecuta la aplicación en un emulador o dispositivo físico.
